Parlay League

A bookmark that swaps the Splash pick'em page for the league view.

Set it up on iPhone

  1. Tap Copy bookmark code above.
  2. Tap the Share button, then Add Bookmark, and name it Parlay League. Save it.
  3. Open your bookmarks, tap Edit, then tap the new bookmark.
  4. Clear the address and paste the code. Tap Done.

Set it up on a Mac

Drag this button to the bookmarks bar: Parlay League

Use it

  1. Open Splash, then tap the Parlay League bookmark.
  2. If you tap it from any other page, it opens Splash first. Tap it again once Splash loads.

Updates arrive on their own. The bookmark always loads the latest version of the script.
